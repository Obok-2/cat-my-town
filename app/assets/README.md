# App icon assets

`brand-mark.png` is the project master mark: an original cat-face and location-pin symbol generated specifically for 우리동네고양이.
It does not use a third-party logo, character, stock image, or trademark.

The launcher icon, Android adaptive icon layers, monochrome icon, splash icon, and favicon are mechanically derived from that master mark.

`level-up-cat.png` is an original flag-holding cat illustration generated specifically for the app's level-up screen.
It does not use a third-party character or stock image.

`registration-complete-cat.png` and `sighting-complete-cat.png` are original illustrations generated for the
new-cat registration and existing-cat sighting completion screens. They do not use third-party characters or stock images.
