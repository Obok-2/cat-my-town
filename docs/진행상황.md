## app/ 현재 상태

- 화면: 스플래시·로그인·카메라·매칭결과·이름짓기·도감·고양이상세·레벨·프로필. 촬영 직후 사진은
  `expo-image-manipulator`로 긴 변 최대 1280px·JPEG 품질 0.82로 줄여 `/app/camera/analyze`에 전송하며,
  `NOT_CAT`·`NEW_CAT`·`EXISTING_CAT` 결과 화면까지 서버와 연결됐다. 나머지 데이터는 로컬(AsyncStorage) 목데이터다.
- 서버 호출은 `src/api/`의 기능별 모듈에서 axios + async/await로 단순하게 처리한다. 카메라 분석 요청은
  `cameraApi.js`가 axios 응답을 그대로 반환하고 화면이 필요한 데이터를 꺼내 쓴다.
- 서버가 일치율 40% 이상 후보를 최대 3명 내려주며 앱은 이를 표시한다. 레벨 5단계(`src/data/levels.js`):
  1·5·12·16·30마리. README의 레벨 4단계·매칭 후보 1개 설명은 이와 어긋나 있음(README 미갱신).
- 고양이 상세 지도: **카카오 지도 JS SDK로 실제 지도 연동됨**(`KakaoMapView.js`/`.web.js`/`kakaoMapDraw.js`).
  좌표나 키가 없거나 로딩 실패하면 격자 자리표시자로 자동 전환. 키·설정은 `AGENTS.md`「지도」 참고.
  **실제 GPS 수집은 없음** — 지금 좌표는 데모 시드(`seed.json`)뿐.
- 실기기·에뮬레이터에서는 아직 아무것도 확인 안 됨(카메라 확대 배율 대략값, 손전등, 지도 WebView 등 전부 웹/헤드리스 브라우저까지만 검증).
- Expo 기본 앱 아이콘을 프로젝트 전용 고양이·위치 핀 마크로 교체했고, 런처·Android adaptive/monochrome·스플래시·favicon 자산을 갖췄다.
  화면 안의 문자 기호도 Ionicons로 통일했으며 라이선스 고지는 `app/THIRD_PARTY_NOTICES.md`에 둔다.

## server/ 현재 상태

- Spring Boot 3.5, **JDK 17+ 필요**(로컬 `JAVA_HOME`은 11 — VS Code Java 확장에 딸린 JDK 21로 우회 가능,
  `C:\Users\Admin\.vscode\extensions\redhat.java-*\jre\21.*\bin\java.exe`).
- 구현된 API: `/app/collection/{count,cats}`(도감), `/app/level/count`(레벨), `/app/cat/{detail,markers,sightings}`(고양이 상세),
  `/app/camera/analyze`(DJL 고양이 판별 + Voyage AI/pgvector 기존 개체 후보 최대 3마리),
  `/app/cat/register`(신규 고양이·첫 목격·태그 등록, MinIO 사진 저장, 대표 임베딩·레벨 갱신). 촬영 분석 응답 상태는
  `NOT_CAT`·`NEW_CAT`·`EXISTING_CAT` 세 가지다. 동일 개체 비교에는 실행 환경의 `VOYAGE_API_KEY`가 필요하다.
  신규 등록은 분석 사진을 다시 multipart로 받는 현재 MVP 방식이며, 기존 고양이 확정 API는 아직 없다.
  코딩 규칙·URL 체계는 `AGENTS.md`「코딩 규칙 (Java)」 참고.
- 인증 없음(`X-User-Id` 헤더로 임시 식별, 기본값 1). Firebase 인증 붙기 전까지 유지.
- 로컬 앱·웹 개발용 CORS는 `WebConfig`에서 전체 경로에 공통 적용한다.
- 앱 카메라 분석과 연결됨. 기존 고양이 확정·신규 등록을 비롯한 나머지 앱 데이터는 아직 로컬 목데이터.

## web/ 현재 상태

- React + Vite(JS), 로그인·대시보드만 실제 동작(목데이터). 나머지 메뉴는 "작업 중" 자리표시자 화면.
- 서버 API에 연결 안 됨.
- 앱과 같은 고양이 마크를 favicon·로그인 화면·관리자 사이드바 브랜드에 적용함.
- 실행: `cd web && npm install && npm run dev`

## infra/ 현재 상태

- 로컬 DB는 호스트 포트 **5455**(기본 PostgreSQL과 충돌 회피), MinIO는 API 9000·콘솔 9001. 실제 DB명·계정명·비밀번호와
  MinIO 관리자 이름·비밀번호는 Git에서 제외된 `infra/.env`에 두고, 키 이름만 `infra/.env.example`로 공유한다.
- 스키마는 자동 적재 안 됨 — 직접 실행: `docker exec -i cat-my-town-db psql -U catmytown -d catmytown < 산출물/schema.sql`

## 산출물/ 현재 상태

- `schema.sql`: 확정 전 초안. 고치면 ERDCloud의 ERD도 같이 맞출 것(주소는 로컬 메모리에만 있음, 저장소엔 없음).
- `앱_REST_API_인터페이스_정의서.md` v0.3: 구현된 API만 최신 주소·응답 형태 반영, 나머지는 예전 초안 그대로.
