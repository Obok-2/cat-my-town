## 폴더 구조 (현재 상태)

```
app/     React Native(Expo, JS) 앱 — 새 목업(a0~a10) 반영 완료(로컬 목데이터 기반), 백엔드 미연동
server/  Spring Boot 3.5 + MyBatis 백엔드 — 도감 API 2개 + 레벨 API(`/app/level/count`) 구현, 촬영은 빈 깡통. 공통 `ResponseApi`·전역 예외 처리 있음
web/     관리자 웹 (React + Vite, JS) — 로그인·대시보드 구현 완료(목데이터), 나머지 메뉴는 "작업 중" 화면
infra/   인프라 설정(Docker Compose) — 로컬 개발용 DB(PostgreSQL + pgvector), MinIO
design/  화면 목업(PDF + HTML 캔버스, 최신은 `우리동네고양이 UIUX 목업/`)
doc/     기획 문서 — 비어있음
산출물/  설계 산출물 — DB 스키마 초안(schema.sql), 앱 REST API 인터페이스 정의서(초안)
docs/    이 진행상황 문서
```

### 2026-09-21 (서버 오류 정보 숨김 점검 + 람다 제거)
- 사용자 지적: 서버 에러를 굳이 알려줄 필요 없음(보안), 람다식은 읽기 어려우니 빼달라. **서버 오류 응답 점검**: DB를 꺼 둔 채 서버를 띄워 실제 DB 접속 예외를 일으켜 봤더니 API 응답은 이미 일반 문구(`{"result":"ERROR","message":"서버 오류가 발생했습니다.","code":500,"data":null}`)뿐이고
  원인(`Connection to localhost:5455 refused` 등)은 서버 로그에만 남음 — 즉 예외 처리기는 원래 상세를 노출하지 않았음
- **발견해서 고친 누수 1건**: 잘못된 URL(`%zz` 같은 깨진 인코딩)은 컨트롤러에 닿기 전에 Tomcat이 자체 HTML 오류 페이지를 내는데, 여기에 **`Apache Tomcat/10.1.55` 버전과 `Invalid URI: […]` 상세**가 노출됐음.
  `TomcatErrorPageConfig`(`WebServerFactoryCustomizer` + `TomcatContextCustomizer`, 람다 없이 클래스로 구현)와 `HiddenErrorReportValve`(서버 정보·상세 리포트 끔)로 숨김 → 이제 "HTTP Status 400 – Bad Request"만 나오고 어떤 응답에도 "Tomcat" 문구 없음(실제 호출로 확인).
  참고: Spring 기본 `/error` 주소는 `{timestamp,status,error,message:"No message available"}` 형태로 남아 있으나 민감 정보는 없음
- **람다 제거**: `CollectionService`의 스트림·메서드 참조 → `for`문+`HashMap`, `GlobalExceptionHandler`의 `->` switch → `if`문, 테스트의 `extracting(::…)` → 개별 `assertThat`. `src/main`·`src/test`에 `->`·`::` 없음. 빌드·테스트 13개 통과
- `AGENTS.md` 규칙 2개 추가(람다·스트림·메서드 참조·화살표 switch 금지 / 서버 오류 상세 미노출). 아직 커밋 안 함 (AGENTS.md 절대 규칙 1조)

  ERDCloud 화면 설정에서 코멘트 표시가 꺼져 있음(`display.comment=false`) — MCP로는 못 바꾸므로 ERDCloud에서 직접 켜야 보임.
  코멘트 문구는 ERD에만 있고 `산출물/schema.sql`은 인라인 주석 수준 — 필요하면 `COMMENT ON` 문으로 맞출 것
- ERD로 표현 안 되는 것(schema.sql에만 있음): 인덱스(HNSW 코사인 등), 복합 UNIQUE `(cat_id, tag)`, CHECK(`match_logs.result`), ON DELETE 규칙.
  일부는 컬럼 설명에 적어 둠. FK 관계선은 ERDCloud 기본값(`ZERO_OR_ONE_OR_MANY`)이라 필수/선택 표기가 실제와 다를 수 있음
- ⚠️ ERD 공개 범위가 `PUBLIC` — 링크를 아는 사람은 볼 수 있음. 필요하면 ERDCloud에서 비공개로 전환
- ERD를 고치면 `산출물/schema.sql`도 함께 맞출 것(두 곳이 어긋나지 않게)
- 아직 커밋 안 함 (AGENTS.md 절대 규칙 1조)
