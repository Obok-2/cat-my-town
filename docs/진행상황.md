## 작업 기록 (최신순)

### 2026-09-21 (app 스캐폴딩)
- `app/`에 Expo SDK 57 blank 템플릿(JS, TS 아님) 생성 — `npx create-expo-app . --template blank`
- 의존성: `@react-navigation/{native,native-stack,bottom-tabs}`, `react-native-screens`, `react-native-safe-area-context`, `react-native-svg`, `@react-native-async-storage/async-storage`, `expo-camera`, `@expo/vector-icons`, `expo-font` — 전부 `npx expo install`로 SDK 호환 버전 설치
- `design/우리동네고양이_목업.pdf` 10페이지를 PowerShell(Windows WinRT `Windows.Data.Pdf`)로 PNG 렌더링해서 화면·컴포넌트·네비게이션 구조(8페이지 "NAVIGATION/SHARED COMPONENTS/DATA SHAPE") 그대로 옮김
- 네비게이션: `AuthStack(LoginScreen)` / `RootTabs(도감·촬영·나, 촬영이 initial)` / `CaptureStack(modal: MatchResult→Naming)` / `CatDetailScreen(push)` — 목업 8페이지 스펙 그대로
- 화면 7개 구현: LoginScreen, CameraScreen(expo-camera), MatchResultScreen, NamingScreen, CollectionScreen, CatDetailScreen, ProfileScreen(목업에 없어 최소 기능으로 직접 추가)
- 공유 컴포넌트: PrimaryButton, GhostButton, MatchGauge(react-native-svg + RN 내장 Animated), LevelProgressBar, TraitTagList, CatCard, SightingTimelineItem, SightingMiniMap, LevelUpModal
- 데이터 레이어(`src/data/store.js`): AsyncStorage 기반 로컬 저장 — `server/`가 비어있어 실제 API 없음. Cat/Sighting 모양은 목업 8페이지 DATA SHAPE 그대로
- 레벨 계산(`src/data/levels.js`): 기획안 §3-3 표(Lv1~4) 기준. 관리자 CMS 목업(6페이지)의 Lv1/3/5/7 표기는 대시보드 예시일 뿐이라 채택 안 함
- ⚠️ **목업(자리표시자) 상태로 남긴 부분**:
  - 로그인: 실제 Firebase/Google 인증 없음 — 버튼 누르면 바로 로그인 처리
  - AI 매칭(`src/data/mockMatch.js`): Voyage AI/Claude 연동 없음 — 로컬 고양이 중 무작위 후보 + 무작위 점수
  - 목격 지도(`SightingMiniMap`): react-native-maps 미적용(Google Maps API 키 없음) — 핀 위치만 흉내낸 정적 뷰, "실제 위치 지도는 준비 중" 문구 표시
- 검증: `npx expo export --platform android` 성공(1060 모듈, 에러 0) — 아직 실기기/에뮬레이터 확인은 안 함. `npx expo-doctor` 21/21 통과
