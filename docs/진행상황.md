- ⚠️ ERDCloud 엔드포인트(Cloudflare)는 파이썬 등 **직접 HTTP 호출을 차단**함(Error 1010 browser_signature_banned, "Do not retry"). 우회하지 말고
  반드시 Claude Code MCP 도구(`mcp__erdcloud__*`)로만 접근할 것
- **ERDCloud에 ERD 작성 완료** (ERD 이름 `cat-my-town`, 주소는 접근 권한과 연결될 수 있어 문서에 적지 않음 — 로컬 메모리에 보관).
  빈 ERD 상태에서 시작(백업 불필요 확인) → 도메인 14개(bigserial/bigint/smallint/varchar 6종/timestamptz/vector1024/numeric 2종) 생성 →
  `import_sql`로 6개 테이블 + FK 6개 한 번에 생성 → 전 컬럼에 도메인 연결, 일부 컬럼에 설명(comment) 추가 → 테이블 배치 정리
- 이어서 **논리명은 한글·물리명은 영어**로 정리(테이블 6개·컬럼 33개, 예: `users`=사용자, `google_uid`=구글 UID)하고 모든 컬럼에 코멘트를 채움.
  ERDCloud 화면 설정에서 코멘트 표시가 꺼져 있음(`display.comment=false`) — MCP로는 못 바꾸므로 ERDCloud에서 직접 켜야 보임.
  코멘트 문구는 ERD에만 있고 `산출물/schema.sql`은 인라인 주석 수준 — 필요하면 `COMMENT ON` 문으로 맞출 것
- ERD로 표현 안 되는 것(schema.sql에만 있음): 인덱스(HNSW 코사인 등), 복합 UNIQUE `(cat_id, tag)`, CHECK(`match_logs.result`), ON DELETE 규칙.
  일부는 컬럼 설명에 적어 둠. FK 관계선은 ERDCloud 기본값(`ZERO_OR_ONE_OR_MANY`)이라 필수/선택 표기가 실제와 다를 수 있음
- ⚠️ ERD 공개 범위가 `PUBLIC` — 링크를 아는 사람은 볼 수 있음. 필요하면 ERDCloud에서 비공개로 전환
- ERD를 고치면 `산출물/schema.sql`도 함께 맞출 것(두 곳이 어긋나지 않게)
- 아직 커밋 안 함 (AGENTS.md 절대 규칙 1조)
