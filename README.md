# 우리동네고양이

산책하며 마주친 길고양이를 사진으로 기록하는 **개인용 고양이 수집 다이어리**.
AI가 "예전에 등록한 고양이와 같은 개체인지"를 판별해서 알려주고, 사용자가 최종 확인하면 기록이 누적되는 구조입니다.

- **Whisker Tracker**(해외 사례)의 "개인 기록장" 철학을 벤치마킹
- 동네 커뮤니티 공유가 아니라 **철저히 개인용 도감** — 내가 찍은 고양이만 내 기록에 남음
- 포켓몬 도감처럼, 만난 고양이를 하나씩 모아가는 수집 재미

---

## 핵심 사용자 플로우

```
1. 로그인 (구글 소셜 로그인)
2. 앱 실행 시 카메라 화면으로 즉시 진입
3. 길고양이 사진 촬영
4. AI 처리
   ├─ 이미지 임베딩 생성 (Voyage AI)
   ├─ 내 기존 등록 고양이들과 유사도 비교 (pgvector, 본인 데이터 내에서만 검색)
   ├─ 무늬 타입 판별 + 매칭 설명 생성 (Claude)
   └─ 가장 유사한 후보 + 신뢰도 % 제시
5. 사용자 최종 판단
   ├─ [맞아요, 같은 고양이예요] → 기존 개체에 목격 기록(sightings) 추가
   └─ [아니에요, 새로운 고양이예요] → 신규 개체(cats) 등록, 이름 짓기
6. 도감(컬렉션) 화면에서 그동안 모은 고양이 확인
```

---

## 핵심 기능

### AI 매칭 (RAG 파이프라인)
- **Retrieval**: Voyage AI 임베딩 + pgvector 코사인 유사도 검색 (본인 소유 데이터로 범위 제한)
- **Generation**: Claude API가 검색 결과를 바탕으로 자연어 설명 + 무늬 타입 판별 동시 처리
- **신뢰도 표시**: 원시 코사인 유사도를 그대로 노출하지 않고, min-max 정규화로 보정한 값을 "일치율 %"로 표시
- **최종 판단은 항상 사용자**: AI는 "제안"만 하고, 등록/매칭 확정은 사용자가 버튼으로 결정

### 특징 태그 판별
고정된 카테고리(카오스/턱시도 등)로 제한하지 않습니다. 외국 품종(스코티시폴드, 페르시안 등)이 섞일 수 있어 AI가 자유 판단한 짧은 텍스트 태그로 표시합니다.
(예: "턱시도", "삼색이", "스코티시폴드로 추정" 등)

### 레벨/도감 시스템
등록한 고유 개체 수 기준으로 레벨업. 도감 화면 상단에 레벨 + 다음 레벨까지 진행률 바를 표시합니다.

| 레벨 | 호칭 | 필요 개체 수 |
|---|---|---|
| Lv.1 | 초보 캣워처 | 1~4마리 |
| Lv.2 | 동네 탐정 | 5~9마리 |
| Lv.3 | 골목 스카우터 | 10~19마리 |
| Lv.4 | 고양이 마스터 | 20마리 이상 |

레벨 값은 매번 COUNT 쿼리 대신, 등록 시점에 계산해서 `users` 테이블에 캐싱합니다.

### 도감(컬렉션)
- 등록한 고양이들을 그리드로 확인 (필터 없이 전체 노출)
- 고양이 상세: 이름, 특징 태그, 목격 타임라인(날짜별 사진)

## 화면 구성

| 화면 | 설명 |
|---|---|
| 로그인 | 구글 소셜 로그인 |
| 홈(카메라) | 앱 실행 시 즉시 카메라 활성화 |
| 매칭 결과 | 후보 사진 + 일치율 % + [같은 고양이예요] / [새로운 고양이예요] 버튼 |
| 이름 짓기 | 신규 등록 시에만 노출 |
| 도감(컬렉션) | 그리드 뷰, 상단 레벨/진행률 표시 |
| 고양이 상세 | 이름, 특징 태그, 목격 타임라인, 미니 지도(경로선 없이 핀만) |

## 신뢰도(%) 보정 로직

원시 코사인 유사도는 다른 개체 간에도 0.75~0.9대로 높게 나오는 경우가 많아 그대로 노출하면 오해 소지가 있습니다. Min-Max 정규화로 보정합니다.

```java
double calibrated = (rawSimilarity - LOWER_BOUND) / (UPPER_BOUND - LOWER_BOUND) * 100;
calibrated = Math.max(0, Math.min(100, calibrated));
```
(`LOWER_BOUND`, `UPPER_BOUND`는 직접 테스트로 도출한 기준값)

## 알려진 기술적 한계

- 범용 임베딩 모델은 **동일 무늬 개체 간 미세 구분**에 한계가 있습니다
  (예: 카오스 무늬 고양이 두 마리를 헷갈릴 수 있음)
- 대응: 자동 확정 대신 **항상 사용자 최종 확인 UX**로 설계해 오매칭 리스크를 사용자 판단으로 보완
- 참고 연구: 동물 개체 재식별 전문 모델 MegaDescriptor(WACV 2024) 대비, 현재는 범용 임베딩(Voyage AI)을 사용 — 향후 전문 모델 도입 검토 가능
